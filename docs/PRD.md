# PRD — Wordville (글마을 달인: Daily Spelling Quest)

> 버전: v0.1 | 날짜: 2026-08-13 | 플랫폼: macOS / Android / Server

---

## 1. 제품 개요

- **컨셉**: 일상 생활/장소(회사, 여행, 부엌, 일상)를 탐험하며 맞춤법 달인이 되어가는 2D 픽셀 게임
- **차별점**: 단어 암기형 퀴즈가 아니라 **소설형 상황극 지문 + 문장/맥락 이해**로 푸는 문제
  - 예: "며칠/몇일" 같은 단어 고르기가 아니라 "오늘이 며칠이다." 같은 **문장 전체로 답**하는 방식
- **목표**: 일상에서 실제로 쓰는 상황에 유용한 맞춤법 학습
- **배포**: GitHub 랜딩 페이지 + GitHub Releases (스토어 배포 없음)

## 2. 타깃 사용자

- 맞춤법/띄어쓰기에 자신 없는 성인 (20~40대)
- 일상 글쓰기(메신저, 이메일, SNS)에서 맞춤법 실수를 줄이고 싶은 사람
- 가벼운 일일 게임을 즐기는 캐주얼 게이머

## 3. 핵심 기능 (MVP)

### 3.1 상황극 에피소드 (게임 루프)
- **시작 화면**: 스플래시(1.2s) → 게임 선택 화면 (오늘의 에피소드 / 퀵플레이 / 과거 에피소드 / 오답 복습 / 주간 랭킹)
- 에피소드 = 하루 스토리 (예: 출근길 → 회의 → 점심 → 퇴근)
- 장면마다 지문(상황극 텍스트) + 문제 1개 출제
- 답 선택: 2~4지선다, **문장형 선택지** (최대한 헷갈리게 구성)
- 틀리면 다음 장면으로 못 넘어감 (재도전 필수)
- 모든 장면 통과 시 에피소드 클리어 → 다음 날 새 에피소드 (일일 게임)
- 과거 에피소드 아카이브: 지난 날짜 목록에서 다시 도전 가능 (완료 표시)

### 3.2 문제 자동 생성 파이프라인
- Render Cron (매일 00:00 KST) → LLM으로 상황극 5문항 생성
- 심판 검증 루프: 정답 명확성 / 난이도 / 선택지 헷갈림 평가, 미달 시 최대 2회 재생성
- 시드 문제 100개: 생성 실패/부족 시 폴백

### 3.3 오답 기억 (개인화)
- 사용자가 틀린 문제 유형을 임베딩(pgvector) 저장
- 다음 문제 선별: "자주 틀리는 유형 우선" + "이미 맞힌 유형 제외"
- 틀린 문제는 오답 몬스터로 등장 → 오답 복습(5문제)에서 사냥

### 3.4 계정/랭킹
- 익명 UUID + 닉네임 (가입 폼 없음)
- 아바타: DiceBear (seed = user_id)
- 주간 랭킹 (게임 내 화면, 순위·이름·점수) + 리그 (exp 기반 브론즈~다이아, 배지 UI는 제외)

### 3.5 macOS 전용
- 메뉴바 아이콘 (NSStatusItem): 오늘의 에피소드 / 1문제 퀵플레이 / 닉네임·스트릭 / 설정 / 종료
- 설정: Dock 표시 여부 토글 (기본 Dock 숨김)
- 일일 리마인더 알림

## 4. 게임화 요소 (v0.2 예정)

- 캐릭터 성장: EXP → 레벨업, 틀린 문제 = 오답 몬스터
- 콤보: 연속 정답 x2/x3 배율, 5콤보 시 아이템
- 데일리 미션/스트릭: "오늘의 한 글자" 불꽃 유지, 7일 연속 시 골든패스
- 랭킹/리그: 주간 랭킹, 브론즈~다이아몬드
- 후순위: TTS 듣기 모드, OCR 현실 맞춤법 지킴이, 커스텀 퀴즈 공유

## 5. 디자인

- **레트로 파스텔 픽셀**: 16px 타일, 스타듀밸리 감성의 따뜻한 파스텔 색감
- 게임 캔버스 360×780 (갤럭시 S26 기준), macOS 동일 크기
- 상황극: 픽셀 배경 + 캐릭터 애니메이션 + 하단 RPG 대화창(타이핑 효과)
- 문제: "문제 출제!" 배너 → 지문 + A~D 선택지 → 정답 축하 / 오답 몬스터 + 재도전
- 폰트: 갈무리 11(픽셀) + 둥근모꼴(대화)
- 에셋: Kenney CC0, itch.io 무료, DiceBear 아바타

## 6. 비기능 요구사항

| 항목 | 요구 |
|------|------|
| 성능 | 60fps, 콜드 스타트 ≤1.5s (맥) |
| API | P95 ≤ 300ms |
| 오프라인 | 답안 제출 큐 → 재연결 시 일괄 전송 |
| 보안 | OpenRouter 키 서버 전용(.env), 로그에 키 노출 금지 |
| 디버그 | 모든 신규 기능 `[INFO] [FEATURE]` 로그 + DebugPanel (AGENTS.md 19.1) |

## 7. 성공 지표

- 일일 플레이 유지율 (스트릭 7일 달성률)
- 문제 정답률 (50~80% 밴드 유지 = 적정 난이도)
- 심판 루프 통과율 (≥ 90%)

## 8. 제약

- 스토어 배포 없음 → GitHub Releases + 랜딩 페이지
- Render 무료 티어: 콜드 스타트 지연 허용, Cron 제한 고려
- Neon 무료 티어: 512MB → 문제는 서버 캐시, 임베딩만 DB 보관
